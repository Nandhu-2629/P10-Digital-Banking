# P10 – Digital Banking Account & Transaction Management System

## CIA-3 Project

A Digital Banking Account & Transaction Management System developed using
Node.js, Express.js, MongoDB Atlas and Mongoose.

The system provides customer onboarding, account management, beneficiary
management, fund transfers, transaction history, account statements and
staff monitoring features.

## Problem Statement

Traditional banking account and transaction processes require secure
customer onboarding, account approval, beneficiary management, fund
transfers and transaction tracking. The project addresses these requirements
by providing a RESTful backend system for managing digital banking operations
with authentication, authorization, validation, transaction controls and
MongoDB-based data storage.
