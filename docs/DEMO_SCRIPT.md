# 8–10 Minute Demo Script

### 0:00–1:00
Introduce the problem and objective.

### 1:00–2:00
Show architecture and MongoDB collections.

### 2:00–3:00
Register a customer. Show pending account.

### 3:00–4:00
Login as staff. Show pending approvals and approve the account.

### 4:00–5:30
Login as customer. Deposit demo funds, add beneficiary and perform a transfer.

### 5:30–6:30
Show transaction ledger and date-range statement.

### 6:30–7:30
Perform a large transaction or large deposit and show suspicious flagging in the staff dashboard.

### 7:30–8:30
Freeze/unfreeze account and demonstrate that frozen accounts cannot transact.

### 8:30–9:30
Run interest job and show the interest ledger entry.

### 9:30–10:00
Explain JWT/bcrypt, validation, centralized error handling, MongoDB transaction and conclude.
